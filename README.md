# GRC Audit Readiness Simulation

> **Portfolio Project:** A simulated Governance, Risk & Compliance (GRC) program built for a fictional SaaS company to demonstrate audit readiness, control management, risk assessment, evidence collection, third-party risk management, customer trust, and continuous compliance.

> **Disclaimer:** This repository is a fictional case study created for professional development and portfolio purposes. It does not contain proprietary information or represent any real organization.

---

# Project Overview

This project simulates the day-to-day responsibilities of a GRC Analyst supporting a growing SaaS organization preparing for external audits and customer security reviews.

The objective was to build an end-to-end compliance program that demonstrates how governance, risk management, security controls, evidence collection, audit support, remediation, and executive reporting work together to support a mature security organization.

# Compliance Scope

Properly defining audit scope ensures that audit efforts remain focused on systems, data, and processes that directly support customer services while avoiding unnecessary audit overhead.

| **Category** | **In Scope** | **Out of Scope** |
|--------------|--------------|------------------|
| **Environments** | Azure Production Tenant<br>Azure Disaster Recovery Environment | Lab/Sandbox Environments<br>Marketing Website |
| **Assets** | Production Servers<br>Administrative Workstations | Standard Corporate Laptops |
| **Data** | Customer Backup Data<br>Protected Health Information (PHI)<br>Cardholder Data (PCI) | Internal HR Data<br>Marketing Analytics |
| **Identity** | Microsoft Entra ID | Legacy Active Directory |
| **Business Processes** | Access Management<br>Change Management<br>Incident Response<br>Backup & Recovery | Marketing Operations<br>Standard HR Onboarding |
| **Critical Vendors** | Microsoft Azure<br>GitHub Enterprise<br>CrowdStrike Falcon | Payroll Provider<br>Catering Services |

# Project Goal

This repository was created to strengthen practical GRC skills by simulating the documentation and workflows commonly used by Governance, Risk, and Compliance teams within enterprise SaaS organizations.

The project demonstrates how multiple governance artifacts connect throughout the compliance lifecycle. Starting from defining the scope, implementing controls, supporting audits, responding to customer due diligence requests, managing third-party risk, and tracking remediation activities.
